# Chapter 11

## The Five Failure Modes

### (A Complete Diagnostic System for the Instrument)

---

### Narration

By now you have learned how to find baseline, detect drift, regulate
gain, recognize craving, and see the ego as a directional process
rather than a self.

The instrument is becoming precise.

But precision creates a new problem.

The more sensitive the instrument, the more clearly you can see when
it is not working correctly.

And there are exactly five ways it fails.

Not metaphorically five.
Not approximately five.

Five.

They have been mapped for twenty-five hundred years under different
names in different traditions. Here they appear as what they actually
are:

Engineering failure modes.

Each one has a specific signature.
Each one has a specific corrective.
And none of them are moral failures.

They are system states.

When you can recognize which failure mode is active and apply the
correct corrective, the instrument recovers.

That is the whole chapter.

**Teacher:**

Everything else is a combination or a consequence.

### The Diagnostic Question

**Teacher:**
Before we name them, learn the diagnostic question.

When something feels off, ask:

> *What is the instrument doing right now?*

Not: what am I feeling?
Not: what does this mean?
Not: what should I do?

Just: what is the instrument doing?

The answer will always be one of five things.

---

### Failure Mode One — Approach Gain Running Hot

**Student:**
What's the first one?

**Teacher:**
The system is pulling toward something.

A pleasant sensation.
An interesting thought.
A desirable state.
A person, memory, or outcome.

Gain is being applied in the approach direction and it is above the
workable threshold.

**Student:**
How does that feel?

**Teacher:**
Restless. Hungry. Reaching.

Sometimes it feels like excitement that won't settle.
Sometimes it feels like obsession.
Sometimes it feels pleasant but keeps escalating.

The signature is: *something keeps pulling the cursor forward.*

**Student:**
And the corrective?

**Teacher:**
Reduce approach gain.

Soften the grip.
Let the object remain without reaching toward it.
Release the forward lean.

You are not destroying the pleasant object.
You are withdrawing the amplification.

**Student:**
That sounds like suppression.

**Teacher:**
Suppression pushes the object away.
This just removes the pull.

The object can still be there.
You simply stop amplifying it.

---

### Failure Mode Two — Avoidance Gain Running Hot

**Teacher:**
The second failure mode is the mirror image.

The system is pushing away from something.

An unpleasant sensation.
An uncomfortable thought.
A state you don't want to be in.
A memory, anticipation, or sensation that feels threatening.

Gain is being applied in the avoidance direction and it is above the
workable threshold.

**Student:**
How does that feel?

**Teacher:**
Tight. Resistant. Braced.

Sometimes it feels like low-grade irritation.
Sometimes it feels like dread.
Sometimes it feels like the system is holding its breath.

The signature is: *something keeps pushing the cursor backward.*

**Student:**
And the corrective?

**Teacher:**
Reduce avoidance gain.

Soften the resistance.
Let the unpleasant object remain without pushing against it.
Release the backward lean.

**Student:**
That also sounds like forcing yourself to accept something bad.

**Teacher:**
Acceptance in the forced sense is still gain — just disguised.

This is not acceptance.

It is the withdrawal of resistance.

The object can remain exactly as it is.
You simply stop amplifying the push.

---

### The Symmetry

**Teacher:**
Notice the symmetry between the first two modes.

Same mechanism.
Opposite direction.
Same corrective: reduce gain.

This is why craving and aversion feel so different but are structurally
identical.

Both are the instrument applying force to a formation.
Both destabilize in the same way.
Both respond to the same basic move.

**Student:**
So the corrective for both is just... less?

**Teacher:**
